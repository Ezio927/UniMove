# Security policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting page:

https://github.com/Ezio927/UniMove/security/advisories/new

Include affected routes or components, reproduction steps, expected impact, and any suggested mitigation. You should receive an initial response within seven days.

## Supported versions

UniMove is currently maintained on the `main` branch. Security fixes are applied there until versioned releases are introduced.
